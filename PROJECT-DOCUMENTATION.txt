10. ORDER STATUS LIFECYCLE
===============================================================

  pending -> scheduled -> preparing -> ready -> collected -> delivered
                                \                  /
                                 -> cancelled / expired

  Walk-in bills: always start as 'ready' (paid at counter)
  Online orders: start as 'pending', advance through pipeline

===============================================================

11. QR CODE SYSTEM
===============================================================

  ONLINE ORDERS:
    - HMAC-SHA256 signed payload: { o: orderId, s: signature, t: timestamp }
    - Generated with 'qrcode' npm package
    - QR_SECRET env var for signing

  WALK-IN BILLS:
    - Plain bill number string (e.g. "VB-20260721-7555")
    - Bill number is also the Firestore document ID
    - Saved to BOTH 'orders' and 'walkin_bills' collections

  VERIFICATION (POST /api/canteen/qr/verify):
    1. Parse input (JSON or plain text)
    2. Check 'orders' collection (walk-in bills saved here)
    3. Check 'walkin_bills' collection (legacy fallback)
    4. Check in-memory state (same Vercel instance)
    5. Return order details or NOT FOUND

===============================================================

12. PAYMENT FLOW
===============================================================

  ONLINE:
    1. Frontend sends order -> Backend creates Razorpay order
    2. Razorpay checkout opens -> Customer pays
    3. Frontend sends payment ID + order ID -> Backend verifies signature
    4. Order saved to Firestore with paymentStatus: 'paid'

  WALK-IN POS:
    1. Cashier adds items in WalkinPOS component
    2. Bill generated locally (subtotal, tax 5%, grand total)
    3. Payment: Cash / UPI / Pending
    4. Bill saved to Firestore (orders + walkin_bills collections)
    5. QR code generated for the bill number
    6. Receipt printable with QR code

  CONVENIENCE FEE: ceil(foodAmount / 100) added to online orders

13. LOCAL DEVELOPMENT
===============================================================

  Prerequisites: Node.js, npm

  Setup:
    1. npm install
    2. Create .env with GEMINI_API_KEY (and optionally RAZORPAY keys)
    3. Place token.json in root (Firebase Admin SDK service account)
    4. npm run dev    (starts Express on port 3000 + Vite dev server)

  Build for production:
    npm run build    (Vite frontend -> dist/, esbuild server -> dist/server.cjs)

  Start production:
    npm start        (node dist/server.cjs)

  Lint/TypeScript check:
    npm run lint     (tsc --noEmit)
