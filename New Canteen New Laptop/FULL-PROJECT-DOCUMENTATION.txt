5. QR CODE SYSTEM
================================================================================

QR Secret (for HMAC signing): AAE2FBE0CA7C3F12C6DB96FE8F368DFB
(Set as QR_SECRET env var on Vercel)

How it works:
  1. Owner generates QR for a canteen (GET /api/canteen/qr?canteenId=...)
  2. QR contains HMAC-signed bill number
  3. Server/Staff scans QR with mobile app camera
  4. Mobile calls POST /api/canteen/qr/verify with scanned code
  5. Server verifies HMAC signature + checks bill exists in Firestore
  6. Returns bill details if valid

11. API ENDPOINTS
================================================================================

All endpoints are on the canteen2.0 server (server.ts):

AUTH:
  POST /api/auth/login        { email, password }
  POST /api/auth/register     { name, email, password, role, phone, registerNumber, collegeId }

COLLEGES:
  GET    /api/colleges              (returns colleges from Firestore or defaults)
  POST   /api/colleges              (create college)
  DELETE /api/colleges/:id          (delete college)

CANTEENS:
  GET    /api/canteens              (list all canteens)
  POST   /api/canteens              (create canteen)
  DELETE /api/canteens/:id          (delete canteen)

SUBCANTEENS:
  GET    /api/subcanteens           (list all)
  POST   /api/subcanteens           (create)
  DELETE /api/subcanteens/:id       (delete)

CANTEEN DATA:
  GET    /api/canteen?canteenId=    (get canteen with items, orders, reviews)
  GET    /api/canteen/menu?canteenId=
  POST   /api/canteen/menu          (add menu item)
  DELETE /api/canteen/menu/:id      (delete menu item)

ORDERS:
  POST   /api/canteen/order         (place order)
  POST   /api/canteen/order/status  (update order status)
  POST   /api/canteen/order/batch-status (batch update)

PAYMENTS:
  POST   /api/canteen/create-order  (create Razorpay order)
  POST   /api/canteen/verify-payment (verify Razorpay payment)

QR CODE:
  GET    /api/canteen/qr?canteenId= (generate QR code)
  POST   /api/canteen/qr/verify     (verify scanned QR)

REVIEWS:
  POST   /api/canteen/review        (submit review)

WALK-IN:
  POST   /api/canteen/walkin-bill   (save walk-in bill)
  GET    /api/canteen/walkin-bills?canteenId= (list walk-in bills)

USERS:
  GET    /api/users                 (list users)
  POST   /api/users                 (create user)
  PUT    /api/users/:id             (update user)
  DELETE /api/users/:id             (delete user)

TEST:
  GET    /api/test                  (diagnostic: dbConnected, razorpay status)
